# doc/ — 项目级文档

本目录存放 protocol 项目的非临时文档：设计、决策、规范、笔记。

## 结构

```
doc/
├── README.md        ← 本文件：说明文档结构与归档规则
└── ...              ← 其他项目级文档
```

## 归档规则

1. **只归档非临时内容**：设计文档、决策记录、规范、笔记归入本目录；临时草稿、过程性内容留在对话或临时文件，不进本目录。
2. **归档去向**：稳定下来的非临时文档，同步归档到个人文档库 `/Users/Repository/memory/protocol/doc/`，保留来源项目名与日期。
3. **合规**：如涉及公司项目内容，注意不得同步到个人 GitHub 等外部服务。

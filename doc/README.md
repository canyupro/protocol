# doc/ — 项目级文档

本目录存放 protocol 项目的非临时文档：设计、决策、规范、笔记。

## 结构

```
doc/
├── README.md                         ← 本文件：说明文档结构与归档规则
├── Protocol插件与项目区设计.md       ← 全局插件与项目区产品设计
├── 项目区文件映射规范.md             ← 项目区资产、映射与链接规则
├── 存量介入方法论草案.md             ← 待真实项目验证的方法论草案
├── experiments/                      ← 本地实验记录（不上传 git）
└── ...                               ← 其他项目级文档
```

## 归档规则

1. **稳定设计文档**：设计、决策、规范和笔记归入本目录；稳定后同步归档到个人文档库 `/Users/Repository/memory/protocol/doc/`，保留来源项目名与日期。
2. **插件模板**：`plugin/protocol-project-area/templates/` 是可执行初始化模板的唯一来源；设计文档只定义字段、职责和链接规则，不复制模板全文。
3. **实验记录**：`doc/experiments/` 存放本地实验、过程数据和临时脚本，已被 git 忽略，不上传。
4. **合规**：如涉及公司项目内容，注意不得同步到个人 GitHub 等外部服务。

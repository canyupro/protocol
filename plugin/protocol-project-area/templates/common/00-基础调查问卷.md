## 7. 代码写入守卫

项目区初始化后，代码写入默认被守卫拦截。解锁路径仅有：

1. 人类签发 `approvals/understanding-approved.md`，确认三项最低理解文档已达标；或
2. 人类签发 `approvals/write-exemption.md`，写明豁免范围、负责人、原因和到期日。

- [ ] 我理解：主施工 agent 不得自行修改批准、豁免或 guard 文件。
- [ ] 我理解：Bash 间接写入和纯文本路径是已知天花板，仍需人类确认与独立验证方兜底。
